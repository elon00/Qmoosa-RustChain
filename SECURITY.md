# Security Policy

## Supported Protocols & Versions
The QMOOSA Ecosystem follows strict deterministic reality verification and post-quantum cryptographic standards (NIST FIPS 203 ML-KEM & FIPS 204 ML-DSA).

| System / Protocol | Branch | Supported | Quality Gate Standard |
| :--- | :--- | :--- | :--- |
| Production Sovereign AI & Contracts | main | Supported | 100/100 EVIDENCE_GATED |
| Legacy Staged Protocols | master | Supported | Deterministic State Hashing |

## Reporting a Vulnerability
Security vulnerabilities should be reported directly to the ecosystem lead via encrypted channels or private GitHub security advisory. Please do not open public issues for sensitive exploits or private key material.
